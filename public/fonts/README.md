# Font Files Required

Please add the following font files to this directory:

## TT Ramillas (for headings)

- `TT-Ramillas-Regular.woff2` (weight: 400)
- `TT-Ramillas-Medium.woff2` (weight: 500)

## Monotype (for body text)

- `Monotype-Light.woff2` (weight: 300)
- `Monotype-Regular.woff2` (weight: 400)
- `Monotype-Medium.woff2` (weight: 500)
- `Monotype-SemiBold.woff2` (weight: 600)

## Notes

- All fonts should be in `.woff2` format for optimal performance
- If you have `.ttf` or `.otf` files, convert them to `.woff2` using tools like:
  - [CloudConvert](https://cloudconvert.com/)
  - [Font Squirrel Webfont Generator](https://www.fontsquirrel.com/tools/webfont-generator)
- Font files should be placed directly in the `public/fonts/` directory
